## 📖 About the project

This project follows directly from **HTML Advanced**. The HTML structure
built there is reused as-is here — this time, the focus shifts entirely to
**CSS and visual styling**, turning the plain semantic markup into the
polished page designed in Figma.

Every section of the page (header, banner, quote, videos list, membership,
FAQ, footer) is styled to match the design file pixel by pixel: colors,
spacing, typography, rounded corners, shadows, and layout.

## 🎯 Objectives

- Translate a Figma design into accurate, maintainable CSS
- Keep CSS selectors as simple as possible (classes over deep nesting)
- Centralize repeated styles instead of duplicating rules
- Reproduce exact colors, fonts, spacing and image placement from the design

## 📝 Notes

- Some values in the Figma file are floating-point numbers; they were
  rounded to the nearest sensible integer.
- The HTML structure is untouched from the previous project — only classes
  were added where needed to style elements cleanly.
